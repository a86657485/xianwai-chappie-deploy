# 章节入口、循环动作与卡片文案调整设计

日期：2026-09-03

## 目标

在不改变页面其他布局、内容和功能的前提下，完成以下调整：

1. 去掉机器人模型周围显示“面子、里子、路子、方子、底子、法子、牌子、种子”的发光热点，并取消直接点击机器人部位进入章节。
2. 保留底部八个章节按钮作为可见的章节入口。进入章节后，机器人继续播放与该部位和章节含义匹配的原版动作，并持续循环；退出章节后恢复首页现有的自动动作轮播。
3. 删除详情卡片上方的英文副标题，但保留“AI 智慧脑”“核心 CPU”等中文语境中的既有缩写。
4. “作品与资料”按钮保持不变。打开后删除“添加自己的图片或视频……”说明，并去掉弹窗顶部“×× · 资料与作品”标题；素材添加、翻页和打包功能保持不变。
5. 完成验证后，将本部署文件夹作为独立仓库发布到 GitHub 账号 `a86657485` 下的新公有仓库 `xianwai-chappie-deploy`，不公开上级文件夹中的其他资料，不额外启用 GitHub Pages。

## 交互设计

### 章节入口

- 不再生成机器人周围的热点按钮。
- 机器人画布仅保留拖动旋转和双指缩放，不再根据点击位置打开章节。
- 底部八个章节按钮、数字快捷键以及详情卡片内的上一部分和下一部分保持原有行为。用户可见的主要入口统一为底部按钮。

### 章节动作

只使用模型已经包含的原版动作，不修改模型、骨骼或动画资源。动作进入章节时开始，以循环模式持续播放；切换章节时平滑切换到新动作；关闭详情时停止章节动作并恢复首页现有状态。

| 章节 | 原版动作 | 中文显示名称 | 选择依据 |
|---|---|---|---|
| 面子 | `Waving` | 挥手致意 | 呼应亮相、展示和交流 |
| 里子 | `Talking (2)` | 交流 · 二 | 以稳定的躯干和手势表达核心能力 |
| 路子 | `Pointing Forward` | 向前指引 | 呼应路径和方向 |
| 方子 | `Using A Fax Machine` | 操作设备 | 重点表现双手操作，与书册和教学应用相符 |
| 底子 | `Arm Stretching` | 手臂伸展 | 展示四肢关节和基本功 |
| 法子 | `Talking (1)` | 交流 · 一 | 呼应思考、表达和人机协同 |
| 牌子 | `Standing Clap` | 站立鼓掌 | 呼应成果、荣誉和共同庆祝 |
| 种子 | `Kneeling Pointing` | 单膝指引 | 姿态和关注点下移，呼应培育新力量 |

### 卡片与弹窗

- 详情卡片不再渲染英文副标题字段，其他中文字段、序号、标题和内容保持原样。
- “作品与资料”弹窗的首个资料页保留章节摘要、展示证据和来源链接。
- 首个资料页不显示顶部标题，也不显示添加素材的说明段落。
- 弹窗右上方原有“＋ 添加图片 / 视频”按钮保留，因为它是功能按钮，不属于需要删除的说明。
- 帮助、来源等其他弹窗的标题不受影响。

## 实现边界

- 只修改 `xianwai-chappie.html` 及必要的自动化验证文件。
- 不改 `index.html` 开场页、模型文件、纹理、校徽、配色、排版、章节正文、镜头参数和其他交互。
- 不添加新依赖，不联网加载资源，不更换现有动画。

## 验证标准

1. 页面不再创建 `.hotspot` 元素，点击机器人不会进入章节，底部八个按钮仍可进入相应章节。
2. 依次进入八个章节时，对应动作均开始播放并保持循环；切换和关闭详情不报错，关闭后恢复首页动作。
3. 八个详情卡片均不显示英文副标题；“AI”和“CPU”等原文缩写仍在。
4. “作品与资料”弹窗不显示“资料与作品”标题和添加说明，摘要、证据、链接、上传、翻页及打包能力仍存在。
5. 页面通过本地静态服务器加载，浏览器控制台无新增错误；桌面和移动尺寸下主要按钮与卡片可正常操作。
6. Git 变更只包含上述范围；公有仓库创建成功，默认分支为 `main`，远端文件与本地提交一致。
